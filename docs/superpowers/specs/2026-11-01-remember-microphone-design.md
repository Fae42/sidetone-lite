# 记住上次麦克风：小改动设计

## 目标

应用重启后自动选中上次成功用于监听的麦克风，减少重复选择；设备不存在时使用当前可用设备，不阻断启动。

## 方案取舍

- **exe 旁 `Jianting.ini`：用户已选择。** 配置便于备份和移植，使用 Windows 自带的 INI API，不增加依赖。
- 当前用户注册表：实现简单且便于多实例共享，但用户明确选择配置文件，排除。

## 实现

- 配置与 exe 同目录，使用 `[Audio]` 节的 `LastInputId` 保存稳定设备 ID。
- 仅在麦克风成功开始监听后写入，避免把未验证的选择记为“上次使用”。
- 启动及设备列表刷新时优先保留当前下拉选择；首次启动没有当前选择时才使用 INI 中的 ID。
- ID 不存在或没有可用设备时回退到首个活动设备，保留 INI 以便设备重新出现后恢复。
- INI 读写失败不阻断监听，不改变音量、噪声门、低周期或其他设置。

## 验证

构建后选择 HyperX 并成功监听，关闭再打开，确认自动选中 HyperX；随后检查正常启动、停止和 Git 提交。
